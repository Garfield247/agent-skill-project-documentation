# 深度避坑档案复盘与永久免疫案例 (Post-Mortems)

## 1. 案例入库价值门槛 (Value Threshold)

- ❌ **坚决不记**：低级拼写手误、少导包、缺少环境依赖等一目了然的问题；
- ✅ **必须入库的高价值案例**：
  1. **高并发与分布式竞态**：Goroutine 竞态破坏内存、分布式锁粒度失当引发死锁、非幂等重试导致资损；
  2. **隐蔽资源与生命周期泄漏**：SQL/HTTP 连接未释放耗尽连接池、Context 传递引发协程永久泄漏、大对象未流式导致 OOM；
  3. **底层框架与三方协议黑盒陷阱**：ORM 隐式默认值覆盖、JSON 64 位整型溢出、三方乱序回调；
  4. **状态机隐蔽非法跃迁**：逆向流分支遗漏、Worker 扫描并发覆盖中间态。
